KIS — tìm đúng một khung hình trong video

Chọn video, nạp một lần, rồi mô tả cảnh cần tìm. Trả về Top-5, nhấn mạnh khung #1 — đúng tinh thần Known-Item Search.

KIS trên video thật cần backend. Chạy python -m ui.app.

AVS — tất cả khung hình khớp trong video

Mô tả tổng quát. Trả về toàn bộ khung hình phù hợp trong video, xếp hạng theo độ tương đồng — đúng tinh thần Ad-hoc Video Search.

AVS trên video thật cần backend. Chạy python -m ui.app.

Hỏi–đáp trên video VQA

Đặt câu hỏi có suy luận (đếm số lượng, xác định ai làm gì) trên video bạn nạp. Hệ tìm cửa sổ keyframe liên quan tới câu hỏi rồi mới trả lời.

VQA trên video thật cần backend. Chạy python -m ui.app.

Cửa sổ keyframe

Tìm kiếm trên video thật bằng SigLIP

Chọn video trong data/videos/, nạp một lần (cắt keyframe + embed), rồi tìm khung hình bằng câu mô tả — truy xuất cross-modal, không cần API key.

Màu:
Mẹo: vẽ khối màu thô (SigLIP hợp ảnh thật hơn nét vẽ). Có câu ở ô tìm → kết hợp.
Tính năng tìm trên video thật cần backend. Hãy chạy python -m ui.app rồi mở http://127.0.0.1:5000, bỏ file .mp4 vào thư mục data/videos/.
(Bản Artifact này chạy mô phỏng nên không nạp được model SigLIP.)

Chuỗi thời gian — cảnh A trước cảnh B

Nhập nhiều cảnh (mỗi dòng một cảnh) theo đúng thứ tự. Hệ thống chỉ giữ các tổ hợp keyframe cùng video, thời điểm tăng dần đúng thứ tự — lọc logic cứng, không phải xếp hạng độ tương đồng (thách thức temporal logic).

Tính năng này cần backend (SigLIP). Chạy python -m ui.app.

Agent tự chọn cách tìm

Gõ một câu — Agent tự hiểu và tự quyết dùng công cụ nào: tìm theo chữ, theo thứ tự thời gian, hay hỏi lại khi mơ hồ. Nó nhớ phản hồi của bạn qua các lượt và trả lời kèm dẫn chứng keyframe.

Tính năng này cần backend. Chạy python -m ui.app.
